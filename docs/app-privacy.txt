PawPost 1.1.0 데이터 보관 안내

Google Drive 대용량 전송 추가 안내
사용자가 공유 대상과 파일을 확인하고 동의한 경우 본인 Google Drive에 비공개로 업로드합니다.
이후 명시적으로 확인한 파일 접근용 Google 계정에만 읽기 권한을 설정하고, 별도로 지정한 이메일에 링크를 SMTP로 발송합니다. 소유자 계정으로 열 경우 비공개를 유지합니다.
PawPost가 생성한 파일에만 접근하는 drive.file 권한을 사용합니다.
Google 로그인은 기본 브라우저의 공식 Google 화면에서 진행합니다.
Google 토큰·선택적 client_secret·업로드 세션 URL은 운영체제 보안 저장소의 PawPost/GoogleDrive/에 저장합니다.
배포본에는 Google 공개 데스크톱 클라이언트의 앱 식별용 ID·프로토콜 매개변수가 포함됩니다. 이는 추출 가능한 공개 앱 설정이며 개발자 개인 계정에 접근하는 토큰이나 서버용 비밀키가 아닙니다. 개인 토큰·비밀번호·OAuth JSON 전체는 포함하지 않습니다.
로컬 cloud 폴더와 cloud-deliveries.json에는 파일 ID·해시·공유 대상·상태 등 비밀이 아닌 기록만 저장합니다.
cloud-spool에는 실패 시 재시도할 임시 파일 복사본을 보관하고 메일 접수 후 정리합니다.
연결 해제나 앱 제거만으로 Drive 파일과 기존 공유 권한은 지워지지 않습니다.
Google Drive에서 직접 삭제하거나 공유를 해제하면 됩니다. 토큰 취소는 Google 연결 관리에서도 가능합니다.
https://myaccount.google.com/connections
가져온 원본 OAuth JSON은 자동 삭제하지 않으니 개인 보안 폴더에 보관하고 공유하지 마세요.
macOS의 설정·기록 위치는 ~/Library/Application Support/PawPost, 인증 정보 저장소는 Keychain입니다.
Mac도 동일하게 사용자별로 저장하며 다른 사용자의 계정 정보는 배포하지 않습니다.

설치파일에는 개발자의 메일 설정·비밀번호·주소록·전송 기록·전송한 파일이 포함되지 않습니다.
처음 사용하는 사람은 자신의 메일 계정을 직접 연결합니다.

현재 Windows 사용자별 저장 위치
• 앱: LocalAppData/Programs/PawPost
• 설정·수신자·전송 기록: LocalAppData/PawPost
• 앱 비밀번호: 현재 Windows 사용자의 Windows 자격 증명 관리자 (PawPost/SMTP/ 네임스페이스)
• 준비/실패 첨부 복사본: LocalAppData/PawPost/drafts 및 spool

앱 비밀번호는 설정 JSON이나 전송 기록에 저장하지 않습니다.
일반 설정과 기록에는 이메일 주소, 파일명·원본 경로, 시간, 전송 상태가 들어가며 별도 암호화 파일은 아닙니다. Windows 사용자 프로필의 접근 권한으로 보호됩니다.
전송이 완료된 첨부 복사본은 정리합니다. 확실히 실패한 첨부는 재시도를 위해 보관합니다.
원본 파일은 읽어서 복사할 뿐 삭제·이동하지 않습니다.

앱이 사용하는 네트워크
사용자가 설정한 메일 서비스에 TLS로 직접 연결해 인증하고, 보내기를 누른 파일을 지정한 수신자에게 첨부합니다.
PawPost 개발자 서버로 파일·계정·분석 정보를 보내지 않습니다. 별도 광고·원격 분석·자동 업데이트 기능은 없습니다.
도움말 버튼은 사용자가 선택했을 때 메일 서비스의 공식 웹페이지를 브라우저로 엽니다.

일반 제거는 사용자 데이터와 앱 비밀번호를 보존합니다. 재설치하면 다시 사용할 수 있습니다.
완전한 데이터 삭제는 제거 전에 앱의 ‘내 계정·기록 관리’에서 직접 선택하세요.
이메일 서비스에 발송된 메일과 첨부파일은 PawPost의 로컬 데이터 삭제로 지워지지 않습니다.
