개인정보와 파일 안내

이 다운로드 페이지

이 페이지에는 회원가입, 계정 입력, 파일 업로드, 광고, 분석 추적 코드, 자체 쿠키가 없습니다. 버튼을 누르면 GitHub Releases에서 설치 파일을 받습니다. GitHub Pages와 Releases는 GitHub가 제공하며 보안 등의 목적으로 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.

PawPost 앱

파일은 사용자가 선택한 발신 메일 서비스 또는 본인의 Google Drive로 전송됩니다. 개발자 계정으로 업로드하지 않습니다. 원본 파일을 수정하거나 삭제하지 않습니다. 메일 비밀번호와 Google 토큰은 운영체제의 자격 증명 저장소에 보관합니다. 앱 설정, 이메일 주소, 파일명과 전송 이력은 사용자 컴퓨터에 저장됩니다.

Drive 공유는 사용자가 확인한 수신자에게만 설정합니다. 사용자 동의 없이 공개 링크로 만들지 않습니다. 앱 연결 해제나 삭제만으로 이미 보낸 메일, Drive의 파일과 공유 권한이 삭제되지는 않습니다. 해당 서비스에서 직접 관리하세요.

배포본은 사용자 계정, 개인 비밀번호, 개인 OAuth 토큰, 원본 OAuth JSON을 포함하지 않습니다. 데스크톱 Google OAuth 앱의 공개 식별 설정은 포함됩니다. 메일 서비스 계정 연결과 Google 로그인은 각 사용자가 직접 수행합니다.

PawPost 1.0.0에는 자체 분석 전송이나 자동 업데이트가 없습니다. 앱 데이터 보관·삭제 상세 안내에서 저장 위치와 계정 삭제 방법을 확인할 수 있습니다.

문의할 때

배포 저장소의 Issues 또는 링크를 보내 준 배포자에게 문의해 주세요. 공개 문의에 비밀번호, OAuth 인증 코드·토큰, 개인 파일, 민감한 로그를 올리지 마세요.
