PawPost 1.1.0 — 파일은 놓기만 하세요. 나머지는 고양이가.

1. 설치 · 업데이트
Windows 10/11 x64: 설치 EXE를 실행하세요. 개발 도구나 .NET SDK는 필요 없습니다.
Mac macOS 15 이상: M1/M2 등 M시리즈는 arm64, Intel은 x64 DMG를 선택하세요.
DMG를 열고 PawPost.app을 응용 프로그램(Applications)으로 옮기세요.
ZIP을 받았다면 Finder로 압축을 풀고 PawPost.app을 응용 프로그램으로 옮기세요.
기존 버전은 ‘프로그램 종료’한 뒤 교체합니다. 설정·전송 기록은 삭제하지 마세요.
1.0.0에서 업데이트해도 사용자 데이터 형식과 저장 위치는 그대로입니다.
Mac Bundle Identifier는 app.pawpost.desktop, Windows 설치 식별자와 계정 저장 위치도 유지합니다.
Mac 업데이트 후 실제 계정 사용 시 키체인 접근을 다시 승인해야 할 수 있습니다.

2. 처음 보내기
① ‘메일 설정’에서 보내는 이메일, 받을 이메일, 메일 서비스의 앱 비밀번호를 입력합니다.
② ‘연결 확인하고 저장’을 누릅니다. 계정 확인만 하며 메일을 보내지 않습니다.
③ 파일을 화면 위 중앙(Mac은 메뉴 막대 아래)에 1초 머물렀다가 놓습니다.
④ 받는 사람과 파일을 확인하고 ‘보내기’를 누릅니다. 여러 파일·폴더는 자동 ZIP으로 묶습니다.
고양이가 안 보이는 환경에서는 ‘파일 보내기 · 꾸러미’의 파일/폴더 선택을 사용하세요.
파일을 드래그만 하거나 Esc로 취소하면 보내지 않습니다. 원본은 수정하거나 삭제하지 않습니다.
자동 전송은 기본 꺼짐이며 설정에서 직접 켤 수 있습니다. 큰 파일 공유는 항상 동의가 필요합니다.

3. 메일 계정
네이버: 메일 환경설정 → IMAP/SMTP 사용함. 네이버ID 2단계 인증에서 앱 비밀번호를 만듭니다.
Gmail: Google 계정 2단계 인증 → 앱 비밀번호. 조직 정책 등에 따라 앱 비밀번호가 제한될 수 있습니다.
네이버/Google의 일반 로그인 비밀번호를 PawPost에 입력하지 마세요.
메일 설정에서 주소를 바꿔 연결 확인 후 저장할 수 있습니다. ‘연결 해제’는 해당 기기의 인증 연결을 제거합니다.
비밀번호·토큰은 Windows 자격 증명 관리자 또는 Mac 키체인에 보관합니다.
macOS 키체인 암호창에는 보통 Mac 로그인 암호를 입력합니다. 메일 앱 비밀번호가 아닙니다.
화면 갱신·메뉴 이동만으로 키체인 암호를 반복 요청하지 않습니다.

4. 큰 파일
‘Google Drive · 큰 파일’ → ‘Google 계정 연결’ → 브라우저에서 자신의 Google 계정으로 로그인합니다.
사용자가 Google Cloud 설정이나 OAuth JSON 파일을 준비할 필요는 없습니다.
첨부 한도를 넘으면 자신의 Drive에 비공개 업로드 후 이메일로 링크를 보냅니다.
링크를 받을 이메일과 파일을 열 Google 계정을 각각 확인하세요. 공유는 명시적으로 동의한 대상만 허용합니다.
이미 압축된 DMG·ZIP·영상은 불필요한 재압축을 생략합니다. ZIP이 반드시 작아지는 것은 아닙니다.
Drive 공간, Google 계정 정책, 메일 서비스 한도가 적용됩니다. 원본 합계 2 GiB / 10,000개 항목 이내가 대상입니다.
Google OAuth 공개 상태와 실제 확인 범위는 다운로드 페이지의 ‘검증 현황’을 확인하세요.

5. 상태 · 재시도 · 종료
준비/압축/업로드/메일 전송 상태와 실패 원인을 표시합니다. 완료는 메일 서버 접수이며 실제 수신은 메일함에서 확인하세요.
실패 시 ‘전송 기록’에서 원인과 재시도를 확인합니다. 결과 불명인 전송은 중복 방지를 위해 메일함을 먼저 확인하세요.
즐겨찾기·최근 수신자는 ‘받는 사람’에서 관리합니다. 완료한 링크는 전송 기록에서 복사할 수 있습니다.
창을 닫으면 백그라운드에서 계속 실행됩니다. 완전히 끄려면 ‘프로그램 종료’를 누르세요.
설정과 계정은 다시 실행해도 유지됩니다. 업데이트는 다운로드 페이지에서 새 파일로 교체하는 방식입니다.

6. 내게 맞게 조정
‘고양이 · 프로그램 설정’에서 감지 너비를 좁게/기본/넓게 선택할 수 있습니다.
1초 유지 조건은 그대로이며, 발이 나타난 뒤에는 넓은 범위에서 파일을 따라옵니다.
애니메이션과 소리를 각각 끌 수 있습니다. 애니메이션을 꺼도 파일 카드와 전송 상태는 유지됩니다.
Google 계정의 권한이 만료되면 ‘다시 연결’로 본인 계정을 연결하세요. 원본과 재시도 기록은 유지합니다.
설정의 도움말·최신 버전 확인에서 공식 다운로드 페이지를 열 수 있습니다.

7. 코드 서명 · 안전한 설치
Windows 코드 서명 및 Mac Developer ID 서명·Apple 공증은 제공되지 않습니다. 제품 버전 1.1.0은 Apple 인증을 의미하지 않습니다.
Mac 앱 번들에는 무결성 확인용 ad-hoc 서명이 있습니다. Gatekeeper는 실행을 차단할 수 있습니다.
다운로드 출처와 SHA256SUMS.txt를 확인하세요. macOS가 해당 앱의 ‘그래도 열기’를 제공하는 경우에만 안내를 읽고 결정하세요.
‘손상됨’, 악성 소프트웨어 경고, 해시 불일치, 또는 ‘그래도 열기’가 없으면 중단하고 문제를 제보해 주세요.
보안 기능 전체 해제, xattr 제거, 키체인 초기화로 해결하지 않습니다.
