1. 내 컴퓨터에 맞는 파일 받기
Windows 10/11 x64 → Windows 다운로드 (6.3.0)
Mac M1/M2/M3/M4 이후 → M시리즈 다운로드 (6.3.1-beta.2)
Intel Mac → Intel 다운로드 (6.3.1-beta.2)
Mac은 macOS 15 이상이 필요합니다.  → 이 Mac에 관하여에서 확인하세요.
브라우저로 Mac 칩을 정확히 구별할 수 없으므로 직접 골라 주세요.

2. 설치하기
Windows: EXE 설치 파일을 실행하세요. SDK·Blender·개발 도구가 필요 없습니다.
Mac: DMG를 열고 PawPost를 Applications로 복사한 뒤 실행하세요.
설치 파일은 모두 무료 베타입니다. Windows도 코드 서명이 없어 보안 경고가 나올 수 있습니다.

Mac의 중요한 제한
ARM64와 Intel 모두 실제 macOS 빌드·앱 창 실행 검사는 통과했습니다.
하지만 Apple Developer ID 서명과 공증은 없으며, Gatekeeper 검사는 거부되었습니다.
CI 배포 정책 검사에는 Notary Ticket Missing과 Internal Xprotect Error가 남았습니다.
Internal Xprotect Error는 미해결이고 안전성 통과를 의미하지 않습니다.
친구가 다운로드한 앱의 첫 실행, Finder 드래그, Mac의 실제 Google·메일 전송은 미검증입니다.
따라서 모든 Mac에서 설치·실행된다고 보장하지 않습니다.

안전하게 확인하기
- 이 다운로드 페이지에서 받은 파일인지 확인하세요. 필요하면 SHA256SUMS.txt와 비교하세요.
- '확인되지 않은 개발자' 안내이고 파일 출처를 신뢰할 때, 시스템 설정 → 개인정보 보호 및 보안에
  해당 PawPost 앱의 '그래도 열기'가 제공되면 그 앱에 한해서 실행 여부를 결정할 수 있습니다.
- '손상됨', 악성 소프트웨어 경고, 또는 '그래도 열기'가 없으면 실행을 멈추고 배포자에게 알려 주세요.
- Gatekeeper를 끄거나 xattr/검역 속성을 지워 강제 실행하지 마세요.
- Apple 안내: https://support.apple.com/ko-kr/102445

SHA-256 확인(선택 사항: 설치를 위해 터미널을 쓸 필요는 없습니다)
Windows PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath '다운로드한 설치파일 경로'
Mac 터미널: shasum -a 256 '다운로드한 DMG 경로'
결과가 다르면 실행하지 말고 다시 받거나 배포자에게 문의하세요.
체크섬은 파일 동일성 확인이며 Apple 공증이나 안전성 인증을 대신하지 않습니다.

3. 내 계정 연결하기
앱의 메일 설정에서 자신의 발신 계정과 받을 이메일을 입력하고 연결을 확인하세요.
메일 서비스에서 요구하는 앱 비밀번호를 사용하세요. 비밀번호는 배포자나 공개 문의에 보내지 마세요.
큰 파일을 보낼 때는 '내 Google 계정 연결'을 눌러 본인의 Google Drive에 로그인하세요.
사용자가 Google Cloud 설정이나 OAuth JSON 파일을 준비할 필요는 없습니다.
Google 연결은 메일 발신 계정 설정과 별개입니다.
Google 공개 전환은 재확인 중입니다. 마지막 확인된 상태는 테스트 모드이며,
테스트 모드에서는 승인된 계정만 연결할 수 있습니다. 연결이 거부되면 배포자에게 문의하세요.

4. 파일 보내기
파일/폴더를 끌어 화면 맨 위 중앙에서 약 1초 기다리세요.
고양이 발이 나타나면 파일을 놓고 받는 사람·ZIP 이름·전송 방식을 확인하세요.
여러 파일은 ZIP으로 묶을 수 있고, 첨부 한도를 넘으면 연결한 본인 Drive를 사용합니다.
공유 대상과 권한에 동의한 후 보내세요. 원본은 수정하거나 삭제하지 않습니다.
업로드 완료와 이메일 전송 완료는 다릅니다. 앱의 최종 결과를 확인하세요.
Esc로 드래그를 취소하면 메일을 보내지 않습니다.

검증된 것과 남은 것
- Windows: 기존 실제 첨부 메일·대용량 Drive 링크 메일 수신 확인. 동일한 설치 파일 보존.
  설치 파일 내장 ZIP의 파일 목록·크기·SHA-256 검증. 현 소스 Windows 빌드 오류 0개.
- Mac ARM64 15.8.2 / Intel 15.7.9: 네이티브 앱 창, 설정 8페이지, Keychain,
  한글 ZIP·원본 보존 테스트, 앱 번들 구조·ad-hoc 서명·DMG 무결성 확인.
- Mac 각 32개 코어·22개 모의 클라우드/로컬 SMTP·14개 UI·13개 패키징 정책 테스트 통과.
  모의 SMTP/Google 테스트는 실제 외부 메일·Drive 테스트가 아닙니다.
- 미검증: 다른 깨끗한 Windows PC의 설치·실행. 친구 Mac 첫 실행·Finder 드래그·실제 계정 전송.
- 미통과: Mac Gatekeeper / Apple 공증. 이번 무료 베타에서 공증 완료로 표시하지 않습니다.

계정/삭제/업데이트
메일 비밀번호와 Google 토큰은 사용자별 Windows 자격 증명 관리자 또는 Mac Keychain에 저장됩니다.
개발자 개인 계정·비밀번호·토큰·전송 기록은 배포 파일에 포함하지 않습니다.
Google 공개 데스크톱 앱 식별 설정은 포함되며, 각 사용자의 로그인이 반드시 필요합니다.
완전한 계정 삭제는 앱 안의 계정·기록 관리 기능을 먼저 사용하세요.
이미 보낸 메일과 Drive 파일은 해당 서비스에서 별도로 관리하세요.
자동 업데이트는 없습니다. 같은 다운로드 주소에서 최신 베타를 확인하세요.
기존 버전은 덮어 지우지 않고 Releases에 보관합니다.
